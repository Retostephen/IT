# Assignment 1 - My First Python Program

## Objective
Learn how to print output in Python.

## Description
A simple program that prints a welcome message along with basic
student profile details (name, school, department, favourite food,
and favourite programming language), followed by a decorative
"STUDENT PROFILE" banner.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python profile.py
```

## Sample Output
```
WELCOME TO PYTHON

Name: John Doe

School: ABC University

Department: Computer Science

Favourite Food: Rice

Favourite Programming Language: Python

*************************
   STUDENT PROFILE
*************************
```
