# Assignment 4 - Simple Calculator

## Objective
Practice arithmetic operators in Python.

## Description
Asks the user for two numbers and displays the result of Addition,
Subtraction, Multiplication, Division, Modulus, and Power. Handles
division by zero gracefully.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python calculator.py
```

## Sample Output
```
Enter first number
20
Enter second number
5

Addition = 25
Subtraction = 15
Multiplication = 100
Division = 4
Modulus = 0
Power = 3200000
```
