# Assignment 17 - Virtual Environment

## Objective
Learn to create, activate, and manage a Python virtual environment.

## Steps

### 1. Create a project folder
```bash
mkdir my_project
cd my_project
```

### 2. Create a virtual environment
```bash
python -m venv venv
```

### 3. Activate it
- **Windows:**
  ```bash
  venv\Scripts\activate
  ```
- **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 4. Install Requests
```bash
pip install requests
```

### 5. Freeze requirements
```bash
pip freeze > requirements.txt
```

## Repository Contents
- `requirements.txt` — generated by `pip freeze`, lists installed
  packages (e.g. `requests`) so anyone can recreate the environment
  with `pip install -r requirements.txt`.
- `README.md` — this file.

## Prerequisites
- Python 3.x installed
- Internet access (for `pip install`)
