# Assignment 10 - Dictionary

## Objective
Practice using Python dictionaries.

## Description
Creates a mini student database storing Name, Age, Course, Phone,
and Email. Users can add students and retrieve information by name.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python mini_database.py
```

## Sample Output
```
Enter Student Name
John

Name : John
Age : 20
Course : Computer Science
Phone : 08012345678
Email : john@gmail.com
```
