# Assignment 7 - Number Guessing Game

## Objective
Practice loops, conditionals, and the `random` module.

## Description
Generates a random number between 1 and 100. The user guesses,
and the program responds with "Too High", "Too Low", or "Correct".
Bonus: limited to 5 attempts.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python guessing_game.py
```
