# Assignment 3 - User Input

## Objective
Learn how to collect and use input from the user.

## Description
A Student Registration System that asks for Name, Age, Department,
Email, Phone Number, and School, then displays a registration
confirmation message.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python registration.py
```

## Sample Output
```
==========================
STUDENT REGISTRATION
==========================

Welcome John

You have successfully registered.

Department:
Computer Science

Email:
john@gmail.com
```
