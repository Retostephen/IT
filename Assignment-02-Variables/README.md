# Assignment 2 - Variables

## Objective
Practice storing and displaying data using variables.

## Description
Builds a Student Information Card storing full name, age, department,
school, level, state, favourite color, and favourite food inside
variables, then displays everything neatly. Bonus: calculates age
from `Current Year - Birth Year`.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python student_card.py
```

## Sample Output
```
==============================
    STUDENT INFORMATION CARD
==============================
Full Name       : John Doe
Age             : 20
Department      : Computer Science
School          : ABC University
Level           : 200 Level
State           : Lagos
Favourite Color : Blue
Favourite Food  : Rice
==============================
Calculated Age (Current Year - Birth Year): 21
```
