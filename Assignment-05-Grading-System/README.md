# Assignment 5 - Student Result Checker

## Objective
Practice conditional statements (if / elif / else).

## Description
Asks for a student's name and score, then displays a remark
(Excellent / Very Good / Good / Pass / Fail) and letter grade based
on the grade table below. Bonus: displays a congratulatory or
encouraging message based on pass/fail.

## Grade Table
| Score Range | Grade |
|-------------|-------|
| 70-100      | A     |
| 60-69       | B     |
| 50-59       | C     |
| 45-49       | D     |
| 40-44       | E     |
| 0-39        | F     |

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python result_checker.py
```
