# Assignment 15 - File Handling

## Objective
Practice reading from and writing to files.

## Description
Manages student records saved in `students.txt`, supporting Add
Student, Save Student, Read Student, and Delete Student.

## Prerequisites
- Python 3.x installed

## How to Run
```bash
python file_handling.py
```

## Notes
`students.txt` is created automatically in the same folder the
first time a student is added.
